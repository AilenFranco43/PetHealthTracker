# 🐾 PetHealthTracker

PetHealthTracker es una aplicación web diseñada para **gestionar y monitorear la salud de las mascotas**, permitiendo a los usuarios registrar información médica, historial clínico, vacunas y tratamientos en una plataforma centralizada.

La aplicación busca facilitar el seguimiento del estado de salud de las mascotas, ayudando a los dueños a mantener organizada la información médica y acceder a ella de forma rápida y sencilla.

---

# 📌 Características principales

- Registro y autenticación de usuarios  
- Creación y gestión de perfiles de mascotas  
- Registro de historial médico  
- Registro de vacunas y tratamientos  
- Carga de imágenes de mascotas  
- Interfaz web responsiva  
- API REST para comunicación entre frontend y backend  

---

# 🧩 Funcionalidades

## 👤 Gestión de usuarios
Los usuarios pueden registrarse e iniciar sesión para gestionar sus mascotas y acceder a su historial de salud.

## 🐶 Gestión de mascotas
Cada usuario puede crear perfiles para sus mascotas incluyendo:

- Nombre  
- Especie  
- Edad  
- Información general  
- Imagen de la mascota  

## 🩺 Historial médico
El sistema permite registrar información médica como:

- Vacunas  
- Tratamientos  
- Controles veterinarios  
- Observaciones médicas  

Toda la información queda centralizada en el perfil de la mascota.

## 🖼 Gestión de imágenes
Las imágenes de mascotas se almacenan utilizando **Cloudinary**, permitiendo una gestión eficiente y escalable de archivos multimedia.
